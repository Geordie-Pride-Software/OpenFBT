OpenFBT setup guide

Build the SteamVR driver, start the tracker app, and get eight body trackers from one webcam.

What you need Build the driver Register it with SteamVR Run it Camera and alignment

What you need

A Windows PC with SteamVR installed, Python, CMake, and the Visual Studio Build Tools with the "Desktop development with C++" workload. You also need a webcam that can see your whole body.

Open a terminal in the OpenFBT folder and install the Python packages:

pip install -r requirements.txt

Build the driver

Run these two commands from the repo root. The first configures the build and the second compiles it.

cmake -S make -B build -A x64
cmake --build build --config Release

When it finishes you will have a folder at build\openfbt. It holds the driver manifest, the settings file and bin\win64\driver_openfbt.dll, laid out the way SteamVR expects. You only rebuild if the C++ code changes.

Register it with SteamVR

SteamVR needs to know where the driver lives. Open a terminal in SteamVR's bin\win64 folder, which is normally inside C:\Program Files (x86)\Steam\steamapps\common\SteamVR, and run vrpathreg.exe with the full path to your build folder in quotes:

vrpathreg.exe adddriver "C:\path\to\OpenFBT\build\openfbt"

If you would rather not use vrpathreg, copy the whole openfbt folder into SteamVR's drivers folder instead. Either way you only do this once.

Run it

Start SteamVR first and put your headset on. The driver loads when SteamVR starts. Then start the app from the repo root:

python -m src.main

A preview window opens with your skeleton drawn over the camera image. Stand upright with your whole body in view, feet included, and press C to calibrate. It samples for two seconds to find the floor. Press Q to quit.

As soon as the app starts sending, eight trackers appear in the SteamVR status window:

  • Hips (waist)
  • Chest
  • Left foot
  • Right foot
  • Left knee
  • Right knee
  • Left elbow
  • Right elbow

The app sends to the SteamVR driver by default. To send to VRChat's OSC trackers instead, add --output osc. To send to both, add --output both.

Camera and alignment

Put the camera in front of you at roughly waist height, a couple of metres back, so it sees you from head to toe.

The tracker space is not yet aligned to your SteamVR play space, so recentre SteamVR first. Stand in the middle of your play area facing the camera, with the camera in the direction you face when you recentre. Then calibrate in your game, for example in VRChat's tracking settings in SteamVR mode, so the trackers sit close enough to your body to bind.

If the trackers appear offset or rotated, that is the missing alignment between the camera and your headset. It can be fixed with an extra calibration step that lines the camera space up with the headset.

The driver listens on UDP port 43210 on localhost. To change it, edit resources\settings\default.vrsettings and pass --steamvr-port to the app with the same number.
